🎬 Animation Mapping (กำหนดท่า + เลือกเฟรมเอง)
—
Mapping แยกตามอาชีพ — เปลี่ยนอาชีพในแผง "ตัวละคร" แล้วระบบจะโหลด Mapping ของอาชีพนั้นให้ถูกต้อง (ไม่ใช้ของอาชีพก่อนหน้า) · ผู้ใช้เป็นคนกำหนดเองว่า Sprite/เฟรมไหนคือท่าอะไร โปรแกรมไม่เดา ไม่วิเคราะห์ภาพ
เพิ่มจาก Timeline:
1. กด "＋ นำเข้า Sprite Sheet" เลือกไฟล์ภาพ Sprite ของอาชีพนี้ (ขนาด/จำนวนเฟรมเท่าไรก็ได้) หรือเพิ่มจาก Timeline ที่วาดในโปรเจกต์
2. กดปุ่ม "เลือกเฟรม" ของท่าที่ต้องการ (เช่น Walk Front) — จะเปิดหน้าต่างกำหนดเฟรม
3. ตั้งขนาดเฟรม W×H และตำแหน่งเริ่มต้น X,Y (โปรแกรมคำนวณ Grid จากขนาดจริงของภาพ) แล้วคลิกเลือกเฟรมบนภาพ — คลิกหลายช่อง = หลายเฟรมใน Animation เดียวกัน เลือกช่องไหนก็ได้ไม่ต้องติดกัน (รองรับหลายท่าในไฟล์เดียว)
4. จัดลำดับเฟรมด้วย ▲▼ · เอาเฟรมออกด้วย ✕ · ตั้ง FPS และ Loop/เล่นครั้งเดียว · ดูพรีวิว real-time
5. กด "บันทึกการกำหนด" — ทำซ้ำกับท่าอื่นจนครบ 6 ท่า (Idle Front / Idle Back / Walk Front / Walk Back / Attack Front / Attack Back)
6. กด "🎮 ทดสอบใน Game Test" — เดิน 8 ทิศ, Idle ตามทิศล่าสุด, โจมตี (หันขึ้น = Attack Back · หันลง/ข้าง = Attack Front), Click-to-Move จะเล่นจาก Mapping นี้ทันที · ท่าที่ยังไม่กำหนดจะแจ้งเตือน ไม่เลือกท่าอื่นแทนเอง
หมายเหตุ: ไม่แก้ Sprite ต้นฉบับ ไม่แก้ Timeline เดิม · Mapping บันทึกไปกับโปรเจกต์อัตโนมัติ
